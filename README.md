# Personal Website

A personal website built with Django to document my learning, building, and professional journey.

This project is intended to grow alongside me over time from showcasing projects and skills to documenting technical experiences, ideas, experiments, and the evolution of my thinking.

The goal is not just to create a portfolio, but to build a long-term record of the work and learning behind it.

## Status

🚧 **In Development**

The website is being built incrementally. More features, content, and technical documentation will be added as the project evolves.

## Technology

* Django
* HTML / CSS
* JavaScript
* PostgreSQL
* Tailwind CSS

*Technical details and architecture will be documented and updated as the project develops.*

## Vision

To create a long-term personal platform that reflects:

* What I have built
* What I have learned
* Problems I have solved
* Ideas and technical opinions I have developed
* How my skills and thinking evolve over time
